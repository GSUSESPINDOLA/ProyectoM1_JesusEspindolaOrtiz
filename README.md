#  COLORFLY - PALETA DE COLORES

Una aplicación web  que genera paletas de colores aleatorios.

## APLICACION

- Muestra colores aleatorios .
- Puedes elegir entre 2 4 Y 6 colores  con un radio button.
- Al presionar el botón  los colores cambian.
- Cada color muestra su código hexadecimal .

## MODO DE ABRIRLO

1. Abre el archivo `index.html` en tu navegador.
2. Selecciona cuántos colores quieres .
3. Haz clic en el botón GENERAR COLORES.


## Archivos

- index.html -  contiene todo el código .
- app.js -  contiene todas las funciones dinamicas.
- styles.css -  contiene todos los estilos.
